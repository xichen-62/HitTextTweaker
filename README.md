# HitTextTweaker

《A Dance of Fire and Ice》判定飘字自定义 mod。

把游戏里的「完美！」「稍快！」「太慢！」等判定文字改成你喜欢的字样（比如「？！强强！？」），还支持自定义颜色和渐变。

## 功能

- 14 个判定档位逐个自定义文字（输入框默认显示游戏自己的文本；把字全删掉 = 这一档不显示任何字；r150 起完美拆成稍快 / X完美 / 稍慢三档，另加一档「完美！合并时」）
- 面板里直接切换游戏的「X完美判定文本」设置（仅完美 / X完美与-完美！+ / X完美（无粒子）与-完美！+ / X完美 / X完美（无粒子） / -完美！+），跟游戏设置菜单是同一个值
- 改完立即生效，不用重启游戏
- 关卡编辑器里试玩同样实时生效，不用重开谱子
- 每档独立颜色：RGBA 滑条调色，默认显示游戏原色
- 渐变：横向（左→右）、纵向（上→下）、四角（左上/右上/左下/右下）
- 「整体渐变」：整段文字从左到右渐变，或退回每个字内部渐变
- UMM 游戏内设置面板，保存到 `config.json`
- UMM 里关掉 mod 开关，判定文字立即恢复游戏原样

## 安装

1. 游戏需装好 UnityModManager（游戏自带 UMM 0.32.5.0 即可，无需额外安装）
2. 把 `HitTextTweaker` 文件夹放进游戏的 `Mods\` 文件夹
   （最终结构：`Mods\HitTextTweaker\Info.json` 和 `Mods\HitTextTweaker\HitTextTweaker.dll`）
3. 启动游戏，打开 UMM 的 Mod Manager（默认 `Ctrl+F10`，若无效请查看 UMM 自己的热键设置）
   列表里出现 `HitTextTweaker`，状态 `Active` 即安装成功

## 使用

- 在 UMM 列表点本 mod 右侧的齿轮/设置按钮，打开设置面板
- 每个判定档位一个输入框，默认填着游戏自己的判定文本，直接在上面改就行（推荐格式「？！X！？」）
- 改完立即生效：下一次判定就用新字，不用重启游戏
- 颜色/文字/渐变改完松手就自动写入 `config.json`，重启后仍保留；底部「保存」可手动兜底
- 把输入框里的字全删掉 = 这一档什么都不显示（判定不飘字）
- 点「恢复默认」= 文字、颜色、渐变一起回到游戏原样
- 在 UMM 里关掉本 mod 的开关后，判定文字会立即恢复游戏原样

### 颜色与渐变

- 每个档位点「调色」展开 R/G/B/A 四条滑条（0.00~1.00），旁边色块实时预览
- 「恢复游戏原色」一键还原该档位的游戏默认颜色
- 开「渐变色」后可选方向：
  - 横向（左→右）：字内部从左到右渐变，2 个颜色
  - 纵向（上→下）：字内部从上到下渐变，2 个颜色
  - 四角：左上/右上/左下/右下 4 个颜色，进阶玩法
- 「整体渐变」按钮（单字渐变 / 整段文字渐变）：
  - 关 = 每个字内部渐变（横向/纵向/四角）
  - 开 + 横向 = 整段文字从左到右渐变
  - 开 + 纵向/四角 = 自动退回每个字内部渐变（单行文字没法按行上下铺）

### 「X完美判定文本」怎么办

游戏 r150 之后在设置里有一个「X完美判定文本」，决定三个完美档怎么显示。本 mod 面板顶部有同名一行，◀ / ▶ 直接改游戏这个设置，改完游戏设置菜单里同步变化。

选「仅完美」这类会把三档合并成同一条「完美！」的预设时，本 mod 统一用「完美！合并时 (PerfectCombined)」那一行的文字和配色；老 config.json 里没有这一档，会自动从 XPerfect 拷一份。

## 从源码构建

需要：

- .NET SDK（有 `dotnet` 即可，`dotnet --list-sdks` 能看到版本）
- 游戏安装目录（用于引用游戏自带的 Unity 程序集）

> 编译走 SDK 自带的 Roslyn `csc`（`-nostdlib+` + 游戏 `Managed` 里的 mscorlib/netstandard）。不要用 `Add-Type`：Unity 这套程序集会先报 CS0012（缺 mscorlib），补上引用又报 CS8021（No value for RuntimeMetadataVersion），两条路都走不通。

```powershell
.\build.ps1 -GameDir "D:\steam\steamapps\common\A Dance of Fire and Ice"
```

脚本会读取 `src\Main.cs`，引用游戏 `_Data\Managed` 里的程序集（mscorlib、netstandard、UnityEngine、TextMeshPro、UnityModManager、0Harmony 等），编译到 `out\HitTextTweaker.dll`。

也可以设置环境变量 `ADOFAI_DIR` 指向游戏目录，然后直接运行 `.\build.ps1`。

## 项目结构

```
build.ps1        编译脚本（需 .NET SDK，走 Roslyn csc）
src/Main.cs      mod 源码（Harmony patch + UMM 设置界面）
dist/            发行包 zip
```
